Start here: what a proxy does

A proxy is a middleman computer. Instead of your computer talking to a website directly, it talks to the proxy, and the proxy talks to the website. The website sees the proxy's address (called the exit IP), not yours.

People use proxies to hide their real IP, to see a website as if they were in another country, to spread many requests over many addresses (scraping, testing), or to get around a block.

A proxy is not a VPN. It only covers the app or browser you point at it, and it does not encrypt anything by itself. Websites that use https:// stay encrypted between you and the site, but the proxy's owner can still see which sites you visit, and can read anything sent over plain http://.

The quick path in ProxyHive:

  1. Press Start scan. ProxyHive downloads public lists and tests every proxy for you.
  2. Working proxies appear in Results. Pick one marked Elite, without an HTTP only tag, with a low latency.
  3. Press Use on that row, then Test my IP in the green bar. It should show a different IP and country.
  4. Point your browser at 127.0.0.1 and the port shown (default 8082), or switch on Also set the Windows system proxy in Settings, Gateway.
  5. When you are done press Disconnect. Your normal internet settings are restored.
Proxy types: HTTP, HTTPS, SOCKS4, SOCKS5

The "type" is the language the proxy speaks. It decides what traffic it can carry.

TypeWhat it isStrengthsLimitsBest for
HTTPUnderstands web requests. For http:// sites it forwards your request. For https:// sites it opens a tunnel with a command called CONNECT.Most common. Works in every browser, curl and scraping library. Can be tested for anonymity.Web traffic only. Many free ones refuse HTTPS tunnels (ProxyHive tags those HTTP only).Browsing and scraping websites and APIs.
"HTTPS"Usually the same HTTP proxy, just one that allows tunnels to https:// sites. In ProxyHive this is called HTTPS-capable (no HTTP-only tag).Needed for almost every modern website.The word is confusing: it rarely means the link to the proxy itself is encrypted.Anything where the site address starts with https://.
SOCKS4An older, simpler tunnel. Carries any TCP connection.Works for more than just web pages.No UDP, no logins, IPv4 only. Your computer usually looks up website names itself, which can leak which sites you visit.When nothing better is available.
SOCKS5The modern tunnel. Carries any traffic, and can pass the website-name lookup to the proxy.Most flexible. Does not read or change your traffic, so it adds no revealing headers. Supports logins and IPv6.ProxyHive tests web (TCP) traffic only. It does not verify UDP support.Apps with a "SOCKS5 proxy" setting (Telegram, SSH, Git, many browsers), and general-purpose use.
Rule of thumb: for websites pick HTTPS-capable HTTP or SOCKS5. For other apps pick SOCKS5. Avoid HTTP only proxies unless you only visit plain http:// pages.
Anonymity levels: Elite, Anonymous, Transparent

This describes what the website can learn about you. ProxyHive tests it by sending a request to a page that echoes back the headers it received.

LevelWhat the website seesVerdict
EliteLooks like a normal visitor from the proxy's address. No sign that a proxy is involved and no trace of your real IP.Best. Use these.
AnonymousYour real IP is hidden, but the proxy adds headers (such as Via) that say "this is a proxy". Sites that block proxies can spot it.OK for simple jobs.
TransparentYour real IP is passed along to the website. It hides nothing.Useless for privacy. Avoid.
UnknownThe test could not run (the proxy would not forward plain HTTP).Treat with caution.
"Elite" is about headers only. It does not mean the proxy is safe or private. The person running it can still see your traffic, and many proxy IPs are already known to websites. SOCKS proxies cannot add headers at all, so they show as Elite unless your own IP leaks.
What the labels and columns mean
  • Latency: how long one complete HTTPS request took through the proxy. Under 1 s is great, 1 to 3 s is fine, over 3 s feels slow.
  • Speed (Mb/s): download speed, only measured if you switch on the speed test in Settings.
  • Country: where websites will think you are.
  • Exit IP / network: the address websites see, plus the city and the company that owns that network (needs the optional location data). A hosting company name means a datacenter proxy, which many sites distrust.
  • HTTP only tag: forwards plain http:// but cannot tunnel HTTPS, so most modern sites will not load. Hide them with HTTPS-capable only.
  • login ✓ tag: this proxy uses a username and password, and ProxyHive has them (the ones you pasted, or listed with the proxy) and sends them automatically. It is not a warning and it asks nothing of you. If a proxy fails with Needs a login instead, it demanded a login that ProxyHive does not have.
  • Health (saved pool): ✓ 3m passed its last check 3 minutes ago. ⚠ 2 fails failed recently and is dropped if it keeps failing.

"Why proxies failed" (shown during a scan):

  • Port timed out / refused / host unreachable: nothing is listening there any more. This is normal; most free proxies are dead.
  • Timed out: it answered but too slowly. If this is most of the failures, raise the timeout.
  • Needs a login: a private proxy. Add it as user:pass@ip:port if you have the details.
  • Wrong protocol: the list called it SOCKS but it speaks HTTP (or the other way round).
  • TLS / certificate error: the proxy tampers with HTTPS. Rejected on purpose, it could be spying.
  • Proxy refused request: it blocks tunnels or is misconfigured.

Free proxies: what to expect (and the risks)
  • Only about 1 to 2 in 100 scraped proxies actually work, and a working one often dies within minutes to hours. Check again right before you use one.
  • They are usually slow, and the owners are unknown. Some log what you do, inject ads or steal logins on plain http:// pages.
  • Never log in to anything important through a free proxy, and prefer https:// sites. ProxyHive already rejects proxies that tamper with HTTPS certificates.
  • For steady, serious work use a paid proxy service. You can import paid proxies in the form user:pass@host:port and test them with the same tools.
Three ways to use a working proxy
  1. The gateway (easiest). Press Use. ProxyHive opens a local proxy on 127.0.0.1:8082 that forwards to the one you picked, and switches proxies for you if you chose Rotate top N. Point your browser at it, or tick the Windows system proxy option.
  2. Directly in an app. Press Copy to get an address such as socks5://1.2.3.4:1080. Enter it in the app's proxy settings, or in a command: curl -x socks5h://1.2.3.4:1080 https://example.com (the h sends website-name lookups through the proxy too).
  3. From your own scripts. The Pool & API tab shows ready-made examples to fetch a fresh proxy by type, country or anonymity.

You can also export lists as plain text, CSV, JSON, a proxychains file or a browser PAC file.

The saved pool and how it stays fresh

Every working proxy is saved in the pool, so your list survives a restart. Each proxy has a failure score: a failed re-check adds 1, a pass removes 1, and a proxy is dropped once its score goes above the limit (Settings, Proxy pool). A good proxy survives one bad moment, while dead ones disappear.

Switch on Keep the pool fresh automatically to have ProxyHive re-check the pool on a schedule and scan for new proxies when it gets small. It is off by default because it uses your internet in the background.

What are lines like http://203.0.113.10:9999:acct42-pool-res.mobile.corp-country-CA-mode-hold-session-9f3c2a7e1b:Pa55w0rdExample{17 October 20-39 - residential,mobile,corporate - CA}?

  • http://203.0.113.10:9999 is the provider's entrance (a gateway), not the address websites will see.
  • The long username carries the settings: the account, the pool (res.mobile.corp means residential, mobile and corporate IPs), the wanted country (country-CA is Canada), mode-hold (a sticky session that keeps the same exit IP for a while) and a session id. The part after the next colon is the password.
  • The {...} at the end is a label added by the provider's panel (date, kinds of IP, country). ProxyHive ignores it.
  • These are paid residential or mobile proxies. They look like home or phone users, so most websites trust them far more than free ones. Treat the username and password like any other password.
  • One gateway can serve many countries: the same host and port with a different username gives a different exit country. If a list repeats the same host and port with different usernames, ProxyHive keeps the first login for that host and port.
Troubleshooting
  • Few or no working proxies. Normal for free lists. Scan again, and read Why proxies failed for hints.
  • Everything times out. Check that no VPN or firewall is blocking connections, raise Timeout per proxy, or lower Parallel checks.
  • My internet slows down or drops during a scan. Too many parallel connections for your router. Lower Parallel checks (try 300) and Parallel port probes (try 500).
  • Test my IP shows my own IP. The proxy died or does not carry that traffic. Pick another one, or use Rotate top N.
  • Websites do not load but HTTP ones do. You picked an HTTP only proxy. Choose an HTTPS-capable one.
  • A site shows a captcha or "access denied". It knows this is a proxy address. Try another country or another proxy, and use the Site check tab to find ones that work for that site.
  • Test my IP says the gateway works, but a site like whatismyip still shows my old IP. The gateway only changes the IP of programs that use it. Check the second line of the test: it tests this browser. If it says the browser is not using the gateway, set the browser's proxy to HTTP 127.0.0.1 and the gateway port, or turn on Also set the Windows system proxy (Chrome, Edge and Brave follow it). If Windows says it did not accept the proxy, start ProxyHive from start-ui.bat or ProxyHive.exe in a normal window, not from inside another app's preview. If you also run a VPN or proxy app (for example one that listens on a local port such as 10808), it may be overriding the Windows proxy, and your "own IP" may really be the VPN's.
  • Windows still uses the proxy after a crash. Start ProxyHive again and it restores your settings automatically, or turn the proxy off in Windows Settings, Network and internet, Proxy.
Glossary
  • IP address: the number that identifies a computer on the internet. Port: the numbered door on that computer a program listens at, written after a colon, as in 1.2.3.4:8080.
  • Exit IP: the address a website sees when you use a proxy.
  • Latency: waiting time. Speed: how much data per second.
  • Datacenter, residential, mobile proxy: where the exit IP lives. Free proxies are almost always datacenter or hacked machines. Residential and mobile ones look like home users, cost money, and are harder for sites to block.
  • Rotating proxy: switches between several proxies automatically.
  • ASN: the number of the company that owns an IP range (for example a hosting provider).
  • CIDR range: a block of addresses written like 10.0.0.0/24.
  • DNS leak: your computer looks up website names itself instead of through the proxy, which reveals which sites you visit. SOCKS5 with remote lookup avoids it.
  • CONNECT: the command an HTTP proxy uses to open a tunnel for https:// sites.
